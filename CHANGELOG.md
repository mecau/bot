# Changelog

## MecauAI 3.1 — крупная модернизация

### Надёжность и сохранность данных
- Атомарная запись JSON и файловых артефактов с уникальными временными файлами.
- Повреждённые JSON-базы сохраняются в отдельные `.corrupt-*` файлы для последующего восстановления.
- Восстановление/нормализация старых пользовательских записей и неполных строк статистики.
- Защита от параллельной обработки нескольких сообщений одного пользователя в сценариях Voice/Vision.
- Более строгие проверки путей пользовательских артефактов.
- Редактирование документов создаёт новую версию и не перезаписывает исходник.

### ИИ и Telegram
- Обновлены системные инструкции для более точных ответов и безопасной генерации кода.
- Централизовано безопасное форматирование Markdown в Telegram HTML.
- Длинные ответы делятся на допустимые Telegram-сообщения.
- Повторные запросы к Groq ограничены, учитывают временные ошибки и Retry-After.
- История пользовательских запросов не сохраняет текст промптов по умолчанию.

### Файлы и генерация
- Ограничены размеры/объём извлечения PDF, DOCX и TXT.
- Разбор документов вынесен из основного event loop.
- Добавлен TTL и общий лимит активных контекстов документов для защиты RAM.
- Сброс многошаговых сценариев очищает также незавершённый сценарий титульника.
- Исправлена нормализация структуры слайдов и проверка точного числа слайдов.
- Исправлена ошибка резервного генератора презентаций с несуществующей переменной.
- Excel-ответы обрабатываются как JSON, добавлена защита от формул/внешних ссылок из недоверенных данных.
- Отказ по перегрузке не маскируется созданием фиктивного резервного Excel-файла.

### Эксплуатация
- Добавлен `/readyz` отдельно от `/healthz`.
- Конфигурация моделей и каналов поддерживает переменные окружения.
- Числовые настройки проверяются и ограничиваются диапазонами.
- Добавлены README, changelog, dev-зависимости и GitHub Actions.
- Добавлены unit-тесты вспомогательной логики (12 тестов).
- APK не добавлялся: приоритет сохранён за Telegram-версией, без отдельного неподдерживаемого Android-клиента.
